1-qadam — Google Cloud’da service account

~5 daqiqa, brauzerda
  1. console.cloud.google.com da loyiha yarating (yoki mavjudini tanlang).
  2. Google Sheets API sahifasida Enable tugmasini bosing.
  3. IAM → Service accounts → Create service account. Nomi: face-date-sheets, rol talab qilinmaydi.
  4. Yaratilgan account’ni oching → Keys → Add key → Create new key → JSON. Fayl kompyuterga yuklanadi — uni hech kimga yubormang va git’ga qo‘shmang.
