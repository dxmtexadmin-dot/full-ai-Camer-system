 5. .ENV FAYLI

   Notepad'da ochib MAJBURIY tahrirlang:

     APP_SECRET_KEY=<tasodifiy uzun satr>
       yaratish:  py -c "import secrets; print(secrets.token_urlsafe(48))"
     BOOTSTRAP_ADMIN_PASSWORD=<o'z parolingiz>
       (faqat users jadvali bo'sh bo'lganda yaratiladi)

       faqat shu kompyuter. Lokal tarmoqdan kirish uchun: 0.0.0.0

     YOLO_MODEL_PATH=data/models/equipment_best.pt
     YOLO_FALLBACK_MODEL=data/models/yolo26x.pt
     YOLO_CONFIDENCE=0.35
     YOLO_IMAGE_SIZE=640
     YOLO_DEVICE=cpu
     YOLO_TRACKER=bytetrack.yaml
     YOLO_DEDUPE_IOU=0.6

     FACE_MODEL_NAME=buffalo_l
     FACE_PROVIDERS=CPUExecutionProvider
     FACE_DETECTION_SIZE=640x640
     FACE_SIMILARITY_THRESHOLD=0.45

     PROCESSING_FPS=10
     PROCESSING_WIDTH=1280
     PROCESSING_HEIGHT=720
     MAX_FRAME_QUEUE=4

     GOOGLE_SHEETS_ENABLED=false
       credentials tayyor bo'lmaguncha false qoldiring (9-bo'lim).

   Model yo'li haqida: YOLO_MODEL_PATH topilmasa YOLO_FALLBACK_MODEL olinadi;
   u ham topilmasa ultralytics internetdan modelni yuklaydi.
   Yo'lni mutlaq (C:\...\data\models\yolo26x.pt) yoki loyihaga nisbatan
   (data/models/yolo26x.pt) yozish mumkin.

 10. MUAMMOLAR VA YECHIMLAR
-------------------------------------------------------------------------------

 [Python topilmadi]
   -> Python 3.11 x64 o'rnating, "Add python.exe to PATH" ni belgilang.
   -> Tekshirish: py -3.11 -V

 [pip install xatosi / SSL / timeout]
   -> Internet/proxy ni tekshiring, keyin:
      .venv\Scripts\python.exe -m pip install --upgrade pip

 [torch ~2.5 GB yuklayapti]
   -> 4.2 qadamda CPU indeksini ishlatmadingiz. Bekor qilib qaytadan:
      .venv\Scripts\python.exe -m pip install torch==2.14.1 torchvision==0.29.1 --index-url https://download.pytorch.org/whl/cpu

 [insightface o'rnatilmayapti / "Microsoft Visual C++ 14.0 is required"]
   -> requirements-ai.txt dagi insightface==2.1 (tayyor wheel) ishlatilsin.
      0.7.x versiyasi manba kodidan yig'iladi va C++ toolchain talab qiladi.

 [buffalo_l yuklanmadi / yuz tanish ishlamayapti]
   -> Internet yo'q bo'lsa: C:\Users\<USER>\.insightface\models\buffalo_l
      papkasini boshqa kompyuterdan ko'chirib qo'ying (~601 MB).
   -> ONNX Runtime provayderini tekshiring: FACE_PROVIDERS=CPUExecutionProvider

 [Kamera OFFLINE / "Kadr olinmadi"]
   -> source raqami to'g'rimi (0, 1, 2...).
   -> Boshqa dastur kamerani egallab turgan bo'lishi mumkin (Zoom, Teams, Camera).
   -> USB kabel/portni almashtiring.
   -> Kamera boshqa tizimda ishlashini tekshiring (Windows "Camera" ilovasi).
   -> scripts\test_camera.py bilan alohida sinang.
   -> USB'da "open OK, read None" holati uchraydi: shunda tizim
      CAMERA_RECONNECT_INTERVAL dan boshlab 5, 10, 20... 60 sekundgacha
      kutib qayta ulanadi - bu xato emas.

 [/live "qotib qoladi" (freeze)]
   -> Preview kadr tezligi pipeline tezligiga teng: CPU'da ~1 FPS.
      Ya'ni oqim 8 FPS da yuboriladi, lekin tarkibi sekundiga 1 marta
      yangilanadi - "qotish" shundan ko'rinadi.
   -> Yechim: YOLO_IMAGE_SIZE=480, PROCESSING_FPS=5 qilib kamaytiring,
      yoki GPU qo'shing (YOLO_DEVICE=cuda:0 + CUDA torch).
   -> Kamera uzilganda preview ham to'xtaydi; logs\app.log da
      CAMERA_DISCONNECTED yozuvi bo'ladi.

 [Kadr 640x480 chiqadi, 1280x720 emas]
   -> PROCESSING_WIDTH/HEIGHT faqat KICHRAYTIRISH uchun ishlatiladi.
      OpenCV manbadan kelgan kadrni kattalashtirmaydi. 1280x720 uchun kamera
      o'zi shu rejimni berishi kerak.

 [Klaviatura / kichik jihozlar aniqlanmayapti]
   -> Umumiy yolo26x modeli (COCO) klaviaturani kamdan-kam topadi.
      Ofis jihozlari uchun equipment_desk_*.pt modelini ishlatish tavsiya etiladi
      (docs\yolo_training.md - o'qitish yo'riqnomasi).
   -> Jihoz kategoriyasining minimal ishonch chegarasi 0.70 (equipment sahifasida).
      Sinov uchun YOLO_CONFIDENCE=0.25 qilib ko'ring.

 [Port band (8000)]
   -> .venv\Scripts\python.exe run.py --port 9000
   -> yoki .env: APP_PORT=9000

 [Baza qulflangan / "database is locked"]
   -> Ikkinchi server nusxasi ishlab turgan bo'lishi mumkin:
      tasklist | findstr python
      taskkill /F /IM python.exe   (barcha python jarayonlarini to'xtatadi!)
   -> Virtual muhit papkasini (venv) nusxalash emas, qaytadan yaratish tavsiya.

 [Login ishlamayapti]
   -> Administrator faqat users jadvali BO'SH bo'lganda yaratiladi.
      Mavjud bazada .env dagi parol o'zgarsa ham eski parol qoladi:
      parolni /settings sahifasidan o'zgartiring yoki
      data\inventory.db ni zaxiraga olib, yangi baza bilan boshlang.

 [UTF-8 / kirill harflari buzuq ko'rinadi (konsol)]
   -> Bu faqat Windows konsolining kodlash muammosi; fayllar to'g'ri.
      PowerShell: $env:PYTHONUTF8=1 ; $env:PYTHONIOENCODING="utf-8"
