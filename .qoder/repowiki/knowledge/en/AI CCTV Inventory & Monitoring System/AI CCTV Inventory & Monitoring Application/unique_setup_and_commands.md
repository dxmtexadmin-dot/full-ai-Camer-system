Application reads environment variables (or a local `.env` file) via `dotenv.load_dotenv` at import time; required dirs (`data`, `data/employees`, `data/evidence`, `data/models`, `logs`, `secrets`) are auto-created by `Settings.ensure_directories`. The first run seeds default equipment categories, a bootstrap admin user (username/password/fullname from `BOOTSTRAP_ADMIN_*`), and a disabled simulation camera through `app.services.bootstrap.bootstrap_database`.
