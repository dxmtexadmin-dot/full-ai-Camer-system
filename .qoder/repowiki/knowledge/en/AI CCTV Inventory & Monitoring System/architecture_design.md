The root wires three child layers together: `run.py` (with `run.bat`/`run.sh` wrappers) boots the FastAPI app via Uvicorn using settings from `app.config.get_settings()` loaded from `.env`; `requirements.txt` pins shared runtime dependencies (FastAPI, SQLAlchemy, OpenCV, gspread, etc.) consumed by both `app` and `scripts`, while `requirements-ai.txt` adds optional AI extras; `pytest.ini` configures the `tests` package to discover `test_*.py` under `tests/` and excludes `.venv`, `data`, `logs`, `secrets`, `scripts`, and `app/ui`. The `app` module exposes the HTTP API and background workers, `scripts` provides standalone CLIs that reuse `app`'s models/config, and `tests` exercises the same stack against an in-memory SQLite database.
