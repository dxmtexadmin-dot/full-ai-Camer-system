All tests live under `tests/` and are driven by a single `conftest.py` that bootstraps a throw-away environment: it sets `APP_ENV=test`, points `DATABASE_URL` at a temp SQLite file, disables Google Sheets and simulation mode, then imports `app.config.Settings` so the app's settings module sees the test env. A session-scoped `settings` fixture reloads configuration; an autouse `fresh_database` fixture calls `reset_for_tests` + `bootstrap_database` before every test to start from a clean schema with seeded reference data. Tests compose state via fixtures (`session`, `admin_user`, `other_user_factory`) and use FastAPI's `TestClient` (lazily created inside the `client` fixture to avoid starting camera threads). Test files are organized one per feature area: `test_api.py` (HTTP smoke & CSRF), `test_camera.py` (OpenCV/Simulation sources), `test_events.py` (de-duplication & review workflow), `test_face_matching.py`, `test_inventory.py`, `test_sheets.py`, `test_association.py`, `test_tracking.py`. External I/O is avoided — cameras use `SimulationSource`, video paths point at `tmp_path`, and no real network or GPU resources are required.
