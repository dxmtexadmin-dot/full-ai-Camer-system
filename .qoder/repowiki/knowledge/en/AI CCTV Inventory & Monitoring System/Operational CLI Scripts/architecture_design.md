Each file is an independent `argparse`-based CLI that bootstraps the application by injecting the repo root into `sys.path`, then calls shared `app.*` layers (`app.config.get_settings`, `app.database.init_db`/`session_scope`, `app.services.*`, `app.utils.logging_config.setup_logging`). There is no cross-import between scripts; they are thin orchestration shells around existing services. Dependency direction is strictly one-way: scripts → app layer (config, database, services, models, utils). External integrations (Google Sheets API, Ultralytics YOLO, OpenCV) are imported lazily inside functions to keep startup fast and failures optional.
